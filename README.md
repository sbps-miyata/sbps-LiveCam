# sbps-LiveCam

東京・蒲田の24時間ライブカメラ（YouTube 配信）をデジタルサイネージに表示するページ。

- 横長 16:9 用（映像を全面に表示）: https://sbps-miyata.github.io/sbps-LiveCam/
- 横に案内欄を並べる版: https://sbps-miyata.github.io/sbps-LiveCam/side.html

配信 ID が変わったら `index.html` / `side.html` の `CONFIG.videoId` を書き換える。
一時的に別の配信を出したいときは URL に `?v=配信ID` を付ける。
